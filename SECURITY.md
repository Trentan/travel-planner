# Security Policy

## Supported Versions

We actively support and patch the latest version of the application.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **NOT** open a public GitHub issue. Instead, please report it directly by emailing the project maintainer:

[trentan@example.com](mailto:trentan@example.com) *(Note: Please update this to your preferred contact email address)*

Please include as much detail as possible to help us reproduce and resolve the issue:
- A clear description of the vulnerability.
- Detailed steps to reproduce or a proof of concept (PoC).
- The potential impact of the issue.

We will acknowledge receipt of your report within 48 hours and work to resolve the issue as quickly as possible. Thank you for helping keep this project secure!

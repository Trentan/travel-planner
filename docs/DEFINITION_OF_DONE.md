# Definition of Done

A task is complete only when:

## Code
✓ Builds successfully  
✓ No new errors  
✓ Code follows existing patterns  

## Testing
✓ Existing tests pass  
✓ New tests added where appropriate  
✓ Regression risk considered  

## UX
✓ User flow is logical  
✓ Loading states handled  
✓ Empty states handled  
✓ Errors handled  

## Mobile
✓ Different screens considered  
✓ Touch interactions work  
✓ Keyboard behaviour checked  

## Release
✓ No obvious bugs remain  
✓ Documentation updated
